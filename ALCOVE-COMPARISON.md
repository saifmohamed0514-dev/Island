# Alcove feature comparison

Reference checked November 15, 2026: [official feature page](https://tryalcove.com/), [complete official changelog](https://tryalcove.com/changelog), and official downloadable 1.7.7 app. The website currently lists changes through 1.7.9. This is an implementation checklist, not a claim of completed parity. Island uses its own code, artwork and branding.

| Feature family, including its published options | Island 2.12 implementation / limits |
| --- | --- |
| Native animation, fast/instant HUD motion, Reduce Motion, rapid reopen, progressive blur, overshoot choice | Implemented: fixed-canvas open/close, Reduce Motion, optional progressive blur and surface spring, plus smooth/fast/instant/elastic HUD response. Visual fixtures cover static layouts; live animation remains a separate check. |
| One/preferred/all displays, automatic active screen, closed-lid/external use, notch height/width tuning, simulated notch or pill | Implemented: existing screen selection plus camera-safe extra width and notchless pill/simulated-notch styles. Physical external-display and clamshell checks remain outstanding. |
| Duo and multiple activities, idle activity, most-recent ordering, restore dismissed activities, Focus replacing music waveform | Implemented: ordered/rotating activities, Duo, independent wing actions, temporary dismissal/restore, idle choice and shared-Focus waveform replacement. Exact custom Focus identity is not exposed by the public sharing API. |
| Swipe to expand/collapse, cycle, dismiss/restore and skip tracks; natural direction; middle click; Option-click alternative action | Implemented: open/close, expanded cycle, dismiss/restore, middle-click, Option-click and natural track skipping. Local monitors are scoped to Island; sliders retain their normal scrolling behavior. |
| System player/apps/browser media, artwork, seek, previous/next, shuffle, repeat/repeat-one, favorite, copy track URL, focus player/tab | Implemented: player menu for shuffle/repeat/favorite when supported, seek, elapsed/total, copy details, verified Spotify link and focus-player actions. Spotify favorite/speed/explicit capability is read from the installed app’s scripting dictionary. Browser-tab selection and arbitrary-system track URL copying are not implemented. |
| Podcasts/live streams, skip intervals, playback speed, explicit and lossless/Atmos metadata, AutoMix | Implemented: reported 15-second podcast skips, prohibition flags, optional Spotify scripting speed, explicit and actual rate display. Lossless/Atmos/AutoMix/live badges and current-track playlist targeting remain incomplete because the current adapters do not report verified metadata for them. No format or live state is inferred from duration or captured PCM. |
| Live audio waveform, optional visualizer, Focus replacement, paused-art opacity, grayscale/clear art, glare, title extras, gradient progress | Implemented: opt-in CoreAudio tap waveform with in-memory RMS, no microphone/file/network recording, pause/lock/snooze cleanup and bounded failure/retry; Focus replacement and all listed artwork/progress styling. Native audio capture permission and real sample delivery remain unverified on this Mac. |
| Sound/brightness/keyboard-backlight/mute HUDs; labels, percentages, relative dB, display/device symbols, glow, gradient and motion speed | Implemented: real compact sliders, labels/values, mute, display symbol, glow/accent/gradient, duration and motion choices. Relative dB is explicitly digital gain, not speaker loudness. Unsupported volume writes do not publish an invented level. |
| BetterDisplay volume/brightness, Apple displays, XDR, modifier brightness adjustments, AirPlay/HomePod/output device picker | Implemented: CoreAudio output selection, native Sound/AirPlay settings entry, optional documented BetterDisplay request/response and OSD transport with display targeting, bounded deadlines, range guards and readback. Direct HomePod/AirPlay session routing and XDR boost controls are not implemented. Device/OS/provider licensing applies; no native hardware readback has been tested for BetterDisplay. |
| Charging, battery percentage, Low Power Mode, remaining time, low-battery sounds | Implemented: existing power controls plus native remaining-time estimates and optional charging/low-battery system sounds. No time estimate is displayed when macOS supplies a sentinel or unknown value. |
| Bluetooth connection/disconnection and low-battery notices, device symbols/parts, AirPods generations/Max colors/EarPods | Implemented: native connect/disconnect observers, periodic battery refresh, separate reported parts, accessory symbols, sounds and audio-output picker. Exact model generations, colors and proprietary 3D device artwork are not synthesized; detailed hardware matrix testing remains pending. |
| Shared system Focus, custom modes, Focus sounds and quiet Sleep Focus | Implemented: approved shared on/off state, waveform replacement, optional change sound and Focus quieting. Specific Focus names/icons, editing system Focus modes and Sleep-only sound exceptions are not implemented by the public sharing API; no private Focus database is read. |
| Expanded calendar, day/event navigation, calendar colors/markers/list choices, subscribed/declined/multiday events, lunar date/year | Implemented: compact month/list and larger searchable calendar, day/month navigation, colors/event dots, list choice, subscribed/declined filters, multi-day clipping and Chinese lunar date/year. |
| Calendar live activity, configurable lead time, dismiss/restore, join/location actions, time-to-leave reminders, third-party calendar opening | Implemented: configurable activity lead/all-day choice, per-occurrence hide/restore, safe meeting/maps links, notification-authorized lead-time reminders, Apple/Fantastical/Notion opening. Lead time is explicitly chosen, not traffic-based travel estimation; some providers open the app rather than a specific event. |
| Weather on empty calendar days, condition/precipitation details, widget styles | Implemented: existing forecast/precipitation detail plus cached empty-calendar-day conditions, selected units and native lock-card glass/clear/solid styles. |
| Lock-screen Now Playing, Focus, weather, battery, connectivity, calendar, volume, artwork/style/offset controls and Keep Awake | Implemented: six optional locked-screen cards, music controls/progress/output volume, artwork/total/style/offset/display controls and Keep Awake. Enabled and private details start off. Actual secure desktop/screensaver visibility needs live confirmation; no authentication changes are made. |
| Hide in fullscreen/games/Mission Control, screen capture privacy, hide inactive media/note symbol, menu-bar controls | Implemented: fullscreen panel input/visibility handling, native transient Mission Control behavior, game/category and selected-app hiding, paused media hiding, menu open/tool/player actions and existing capture exclusion. Capture exclusion depends on the recorder and OS. Hardware fullscreen/Mission Control transitions still need live checks. |
| Custom notification duration, system sounds, preview/low-battery/connectivity/lock/unlock sounds | Implemented: HUD duration and optional native sound choices/previews/volume for power, device battery/connections, shared Focus, lock and unlock. Focus quieting and per-event throttles apply. Native notification duration remains controlled by macOS. 1.7.9 temporarily removes native banner suppression; Island does not suppress other apps’ banners. |
| Settings sync, optional HUD sync, onboarding, localization, login/update/menu-bar preferences | Implemented: existing setup/login/update consent plus typed appearance/layout/tray/gesture export/import and user-selected iCloud Drive folder sharing, optional automatic local sharing and separate HUD appearance. Incoming changes require review; OS grants, recording, credentials, bookmarks, notes, events, login and update choices stay outside files. No CloudKit/account entitlement is claimed. |
| Paid license/device activation management | Not applicable: Island is GPL open source and has no paid activation/device limit. |

This is not complete one-for-one parity. The explicit remaining differences are provider-specific media metadata/commands, exact system Focus identity, direct AirPlay/HomePod routing, XDR boost and detailed hardware/screensaver validation. Island uses independent controls and artwork; removed historical options are not promises of current Alcove behavior. Optional account/device/OS features need their intended live environment; test fixtures are recorded separately.

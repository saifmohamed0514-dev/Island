# Install Island

1. Download the DMG from https://github.com/saifmohamed0514-dev/Island/releases/latest.
2. Open it and drag Island.app onto Applications. Quit an older Island before replacing it.
3. Open Island from Applications once.

## If macOS blocks the first launch

This development preview is locally signed, but is not Apple-notarized or Developer ID-signed. If you trust the Island download you chose:

1. Dismiss the blocked-app message.
2. Open System Settings → Privacy & Security and scroll to Security.
3. Find the message for Island and choose Open Anyway. Some macOS versions show an Open button first.
4. Complete the Mac’s authentication prompt yourself, then choose Open when asked.
5. Launch Island from Applications and follow its setup guide.

Open Anyway is normally available for about an hour after a blocked attempt. If it is missing, try opening Island again first. A managed Mac may require its administrator.

This is a manual exception for the selected app. Island does not change your Mac’s security protections automatically. Only approve a download whose source you trust.

Apple’s instructions: https://support.apple.com/102445

## Updates

Choose your update preferences in Island Settings → Updates. Existing notes, files, timers and settings are preserved when replacing Island. Open Anyway instructions are also in Settings → Overview and Help & Tips.

Island 2.2 — development preview

Run Island.app on an Apple silicon Mac with macOS 15 or newer. Quit other notch utilities first to avoid overlapping overlays. This build is locally signed, not Apple-notarized; macOS may block it after downloading to another Mac.

YOUR ISLAND
The player, tray, dashboard, settings, welcome flow, icon and compact activities now use Island’s own design. A completed timer clears its compact Done indicator after four seconds. It does not leave a strip under the camera.

YOUR TIMER
Choose Focus. Drag the ring while paused. Use + to enter a duration and save a preset. Settings → Focus & Sounds manages presets, work/break cycles and ringtones. Timer state persists across relaunch.

YOUR MODULES
Settings → Modules enables, reorders and chooses your starting module. Settings → Dashboard chooses four widget slots and an optional daily Work/Minimal schedule. More contains overflow modules. Pin keeps Island open. Displays chooses screens; Behavior configures keyboard shortcuts; System Controls has HUD replacement and permission connections.

OPTIONAL CONNECTIONS
Calendar, Reminders and Mirror ask for their permissions when selected. Weather uses your city search. Code Hosting uses explicit refresh and Keychain tokens. Translation defaults to local Ollama; OpenAI is optional, needs a separate API key/model, sends the entered text only on Translate and may incur API charges. Agents & Inbox prepares local hook examples without changing your Claude/Cursor settings. Bluetooth and window layouts depend on macOS permissions and device support.

WHAT IS INCLUDED
Island.app, corresponding source and local Git history in Source, licenses, build/release scripts, tests, verification report and beginner publishing guide. No user preferences, passwords, private signing keys or account tokens are included. Automatic updates remain off until your own release feed and public key are configured. Nothing has been uploaded.

STATUS
This remains a development preview, not verified full MacNotch parity. FEATURE-STATUS.md lists remaining scope and VERIFICATION.md records actual checks. The previous privileged Low Power Mode toggle is not reconstructed in this source; Battery Settings opens the macOS control.

Island 2.6.0 (260) — development preview

INSTALL
Run Island.app on an Apple silicon Mac with macOS 15 or newer. Keep one copy in Applications and quit other notch utilities to avoid overlapping overlays. This build is locally signed, not Apple-notarized; macOS may block it after downloading to another Mac.

YOUR ISLAND
The player, tray, dashboard, settings, welcome flow, icon and compact activities use Island’s own design. Opening and closing keep the content layout stable while the outer surface resizes and fades. A completed timer clears its compact Done indicator after four seconds. Battery percentage is inside the icon; its pop-up uses system-linked native glass on supported macOS versions.

YOUR TIMER
Choose Focus. Drag the ring while paused. Use + to enter a duration and save a preset. Settings → Focus & Sounds manages presets, work/break cycles and ringtones. Timer state persists across relaunch.

PERMISSIONS, TOGETHER
Settings → Permissions is the home for access setup. Select the features you want, then choose Set up selected. Existing approvals are skipped; manual System Settings steps are checked when you return. Not now and Finish later keep setup optional. macOS requires separate privacy approvals; one Touch ID check cannot grant them all. Camera access alone never starts the mirror. Files are approved when selected, and client hooks remain subject to their own review.

YOUR MODULES
Settings → Modules is a four-position module canvas. Drag a card into a space INSIDE the black preview. Drag an existing block between spaces to swap; a new card replaces the block you drop onto. Click a block for settings. The first drop applies this arrangement to the real Island as its Dashboard. Click a real block for full controls; the grid button returns to your layout. Remove a block with Drop to remove or Show in layout. Enable module separately controls whether its feature remains active. Undo restores the previous arrangement. Turning off Use this layout in Island restores the classic Dashboard, and keeps your custom arrangement. Preview contents are illustrative and do not start cameras, timers or connections. Settings → Dashboard chooses four widget slots and an optional daily Work/Minimal schedule. More contains overflow modules. Pin keeps Island open. Displays chooses screens; Behavior configures keyboard shortcuts; System Controls has HUD replacement and permission connections. Language & Help includes core Arabic labels, an in-app guide and a private diagnostic summary.

POWER CONTROLS
Open Settings → Permissions and select Low Power Mode, then choose Set up selected. Approve the normal macOS administrator dialog. The dedicated service only changes Low Power Mode. Normal toggles need no password; an ad-hoc preview update can require setup again. See Source/Power/README.md. Live authorization remains a separate check in this preview.

CHATGPT, CLAUDE AND CURSOR
Enable AI Coding and Inbox. Settings → Agents & Inbox prepares a helper, six ChatGPT/Codex hook examples and a portable plugin in a private folder. Merge the intended hooks or install the plugin, then review and trust them in the client. Do not install both forms. The app’s setup does not edit client settings. Local Work/Codex sessions are supported; ordinary web chats do not emit local hooks. A draft button opens text in ChatGPT without sending it. See Source/Integrations/README.md.

OPTIONAL CONNECTIONS
Calendar, Reminders and Mirror ask for permission when selected. Weather uses a manual city and has an hourly chart. Code Hosting uses explicit refresh, pagination and Keychain tokens; Jira changes require confirmation. Translation defaults to local Ollama; OpenAI is optional, needs a separate API key/model, sends the entered text only on Translate and may incur API charges. Bluetooth readings and window snapping depend on macOS permissions and device support. Device and wellbeing alerts are optional and run while Island is running.

WHAT IS INCLUDED
Island.app, corresponding source and local Git history in Source, licenses, build/release scripts, tests, verification report and beginner publishing guide. No user preferences, passwords, private signing keys or account tokens are included. Automatic updates remain off until your own release feed and public key are configured. Nothing has been uploaded.

STATUS
This remains a development preview, not verified full MacNotch parity. FEATURE-STATUS.md lists remaining scope and VERIFICATION.md records actual checks, including what has not been tested live.

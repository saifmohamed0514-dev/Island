Island 2.11.1 (21101) — development preview

INSTALL
Run Island.app on an Apple silicon Mac with macOS 15 or newer. Keep one copy in Applications and quit other notch utilities to avoid overlapping overlays. This build is locally signed, not Apple-notarized; macOS may block it after downloading to another Mac.

YOUR ISLAND
The player, tray, dashboard, settings, welcome flow, icon and compact activities use Island’s own design. Opening and closing keep the content layout stable while the outer surface resizes and fades. A completed timer clears its compact Done indicator after four seconds. Battery percentage is inside the icon; its pop-up uses system-linked native glass on supported macOS versions.

YOUR TIMER
Choose Focus. Drag the ring while paused. Use + to enter a duration and save a preset. Settings → Focus & Sounds manages presets, work/break cycles and ringtones. Timer state persists across relaunch.

FIRST START
Island first asks about opening at login and automatic updates, then everyday preferences and permission setup. A hands-on tutorial teaches opening Island, File Tray, the focus ring, module dragging and optional tools, before real module customization. Drag modules into the black preview; click them for settings. Finish later keeps your choices and starts Island without requesting the remaining access. Reopen the guide with Set up Island in the menu or Settings → Overview. Existing settings are kept when you update.

WINDOW SNAPPING
Turn on Snap windows in setup or Settings → Window Snapping, then allow Window and system controls in Permissions. Drag a window’s title bar to the actual left, right, top, bottom or corners of the display and release. Preview frames leave room for the menu bar and Dock. Some apps enforce minimum sizes; full-screen windows need to leave full screen first. The Window Layouts module also offers manual buttons and an app picker.

PERMISSIONS, TOGETHER
Settings → Permissions is the home for access setup. Native requests keep their approval prompt in focus; Island opens System Settings only when you click its explicit button. Some access, including Accessibility, must be enabled using a switch there. Select the features you want, then choose Set up selected. Existing approvals are skipped; manual System Settings steps are checked when you return. Not now and Finish later keep setup optional. macOS requires separate privacy approvals; one Touch ID check cannot grant them all. Camera access alone never starts the mirror. Files are approved when selected; optional plugins are reviewed in the connected client.

YOUR MODULES
Settings → Modules is a four-position module canvas. Drag a card into a space INSIDE the black preview. Drag an existing block between spaces to swap; a new card replaces the block you drop onto. Click a block or top navigation icon for settings. More opens settings for the remaining enabled modules. The Module settings picker and Open settings button reach every section directly, including File Tray. Each module opens in a full-height settings panel, with its own module picker and Done button. The first drop applies this arrangement to the real Island as its Dashboard. Click a real block for full controls; the grid button returns to your layout. Remove a block with Drop to remove or Show in layout. Enable module separately controls whether its feature remains active. Undo restores the previous arrangement. Turning off Use this layout in Island restores the classic Dashboard, and keeps your custom arrangement. Preview contents are illustrative and do not start cameras, timers or connections. Settings → Dashboard chooses four widget slots and an optional daily Work/Minimal schedule. More contains overflow modules. Pin keeps Island open. Displays chooses screens; Behavior configures keyboard shortcuts; System Controls has HUD replacement and permission connections. Language & Help includes core Arabic labels, an in-app guide and a private diagnostic summary.

POWER CONTROLS
Open Settings → Permissions and select Low Power Mode, then choose Set up selected. Approve the normal macOS administrator dialog. The dedicated service only changes Low Power Mode. Normal toggles need no password; an ad-hoc preview update can require setup again. See Source/Power/README.md. Live authorization remains a separate check in this preview.

CHATGPT AND CLAUDE
Settings → Agents & Inbox → Get the plugins creates the ChatGPT/Codex plugin and Claude Desktop installer in a private folder. Install and review Island in the matching client, then select it in a new supported local chat. It uses the account already signed in there and needs no hooks or separate Island account. Tasks using the plugin can show progress and ask questions; answer in Island. It does not automatically monitor every chat or replace native security approvals. Keep Island installed in Applications. Older hook connections are optional under Advanced. See Source/Integrations/README.md.

OPTIONAL CONNECTIONS
Calendar, Reminders and Mirror ask for permission when selected. Weather uses a manual city and has an hourly chart. Code Hosting uses explicit refresh, pagination and Keychain tokens; Jira changes require confirmation. Translation defaults to local Ollama; OpenAI is optional, needs a separate API key/model, sends the entered text only on Translate and may incur API charges. Bluetooth readings and window snapping depend on macOS permissions and device support. Device and wellbeing alerts are optional and run while Island is running.

WHAT IS INCLUDED
Island.app, corresponding source and local Git history in Source, licenses, build/release scripts, tests, verification report and beginner publishing guide. No user preferences, passwords, private signing keys or account tokens are included. The GitHub release feed is configured. Update checks and downloads remain optional in Settings → Updates. A signed release must be published before the feed is available.

STATUS
This remains a development preview, not verified full MacNotch parity. FEATURE-STATUS.md lists remaining scope and VERIFICATION.md records actual checks, including what has not been tested live.

UPDATES AND CURRENT LIMITS
Settings → Updates controls consent, check frequency and installation timing. A release signing key is ready in the owner’s Keychain; its private half is never in this download. The release channel is https://github.com/saifmohamed0514-dev/Island. A signed latest release must be published there before automatic delivery can work. The source includes Set Up Updates.command and a publishing guide. MACNOTCH-COMPARISON.md records the current feature audit and missing details. This preview does not yet have full MacNotch parity or Apple notarization.

In Settings, the question-mark button explains the current page. Help & Tips is searchable. Modules → Layouts can save and switch up to 12 of your own arrangements; Undo restores a removed saved layout. Your content and account settings are kept.

Use Settings → Trays to choose tools and closed-Island activities. Agents & Inbox creates hook-free plugins for ChatGPT/Codex and Claude; install and review them in the matching client, then select Island for a task. They show progress and questions sent by that plugin, not every chat automatically.

NEW IN 2.11
Saved layouts also remember compact activity order, enablement and rotation. In Dashboard settings, choose your own saved daytime/other-hours layouts; shared system Focus uses those same choices when available. Old saved layouts keep your current trays until explicitly updated.

Settings → Trays → While closed has a black interactive preview: drag activities into it to add, drag its cards to reorder, or click a card for module settings. Arrow buttons and Undo remain available. Hover over the closed music activity to play, pause or skip; click artwork to open the player. Turn Music controls on hover off to use ordinary hover-to-open.

NEW IN 2.11.1
The Island panel now meets the screen edge, clamps its closed height to the physical camera area, and refreshes its placement after display changes. Agents & Inbox shows each client’s connection and last activity separately. Use Update plugin files after an app update, reinstall the updated package in your client, and start a new supported local chat. Copy connection-test message gives you a short test to paste there. Enabled plugins report meaningful work and ask questions in Island; compatible local work sessions have a fallback when their MCP tools are unavailable. This still requires the client to use Island and does not monitor every chat automatically. In Trays, Prefer active AI work lets reported work appear ahead of music and timers without replacing controls you are hovering over; pending questions retain priority.

IF MACOS BLOCKS THE FIRST LAUNCH
Try opening Island from Applications once. If you trust the download, open System Settings → Privacy & Security, scroll to Security, and choose Open Anyway for Island. Some macOS versions show Open first. Approve the Mac’s own authentication prompt, then choose Open. See INSTALL.md and Settings → Help & Tips for the full steps and Apple’s support link. This preview is not Apple-notarized or Developer ID-signed.

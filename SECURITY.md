# Security policy

This development preview has no hosted security-report destination yet. Do not submit Island-specific vulnerabilities to Boring Notch's maintainers.

Before publishing a public repository, enable GitHub private vulnerability reporting and update this policy with its URL. Do not include credentials or personal files in public issues. Keep update-signing secrets outside the repository. Until production signing, notarization and an actual old-to-new upgrade have been tested, this preview is intended for local development.

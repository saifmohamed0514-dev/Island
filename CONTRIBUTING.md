# Contributing to Island

Island is GPL-3.0 and based on TheBoredTeam/boring.notch. Preserve original copyright notices and dependency licenses.

1. Read FEATURE-STATUS.md and open or discuss a focused issue in Island's own repository once it is published.
2. Create a branch, make a focused change and update relevant documentation.
3. Run scripts/build.sh. It checks timer persistence, update configuration and release signatures as well as building the app.
4. Describe behavior, checks and limits in your pull request. Never commit private signing material or user data.

For display/UI changes, record the displays and macOS versions actually tested. For a release, follow docs/RELEASING.md. This local repository is not connected to GitHub yet.
